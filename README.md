# Quiz App

A browser-based multiple-choice quiz built with HTML, CSS, and vanilla JavaScript.

## Features

- Display questions with multiple answer choices
- Check selected answers and show correct/incorrect feedback
- Track the user's score
- Move through the quiz with a next-question control
- Restart the quiz after completing it

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation and Event Listeners

## Run Locally

```bash
git clone https://github.com/aya-aboelkheir/Quiz-App.git
cd Quiz-App
```

Open `index.html` in your browser.
